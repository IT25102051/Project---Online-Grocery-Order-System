# 🛒 FreshCart - Online Grocery Order Management System


## 📋 Project Overview

FreshCart is a comprehensive **Online Grocery Order Management System** built using Java web technologies. It allows users to browse products, add items to cart, place orders, make payments, and manage their profiles. Administrators can manage users, products, inventory, orders, and reviews through a dedicated admin panel.

### 🎯 Project Objectives

- Apply Object-Oriented Programming concepts (Encapsulation, Inheritance, Polymorphism, Abstraction)
- Implement CRUD operations using file handling techniques
- Create a user-friendly, responsive web interface
- Demonstrate MVC architecture implementation

## ✨ Features

### 👤 User Module
- User Registration & Login
- Profile Management
- Password Change
- Role-based Access (Admin/Customer)

### 📦 Product Module
- Browse Products by Category
- Search Products
- View Product Details
- Product Reviews & Ratings

### 🛒 Cart & Order Module
- Add/Remove Items from Cart
- Update Quantities
- Place Orders

### 💳 Payment Module

### 📊 Inventory Module

- Low Stock Alerts
- Supplier Management

### 🔔 Notification Module
- Order Updates

- Real-time Notifications

### ⭐ Review Module
- Write Product Reviews

### 👨‍💼 Admin Module

- Product Management (CRUD)
- Order Management
- Inventory Control
- Payment Monitoring

- Broadcast Notifications
